# SaaS capability watchlist

Capabilities a SaaS usually needs that this foundation deliberately doesn't have yet. Each one waits for its trigger, and none is a requirement until a milestone pulls it in (`docs/roadmap.md`, M5). When a trigger fires, start from the "first option" and re-check the candidate, because tools and licences change.

Source: a review on 2026-11-05 of 24 self-hosted and lightweight-stack tools against this repository. Facts were checked that day against each project's own repository, licence file and docs. The full evaluation is kept outside the repository by the owner. Tools that were rejected or found not relevant aren't listed here (for example Bun, Kamal, SQLite as the primary database, Netdata, Uptime Kuma, n8n, Forgejo and Vaultwarden).
